# Memory IA

Jeu de Memory à 2 joueurs pour réviser le vocabulaire anglais de l'intelligence artificielle :
il faut associer chaque **mot** (carte verte) à sa **définition** (carte jaune).

## Jouer
Ouvrir `index.html` dans un navigateur (aucune installation nécessaire).
Pour une adresse en ligne : *Settings → Pages → Deploy from branch → main / root* sur GitHub.

## Règles
- Chaque joueur retourne 2 cartes à son tour.
- Si le mot et la définition vont ensemble : +1 point et les cartes disparaissent.
- Option sur l'écran d'accueil : le joueur qui trouve une paire rejoue.
- À la fin, le gagnant s'affiche en grand.

## Modifier le vocabulaire
Changer la liste `PAIRS` au début du script dans `index.html`.
